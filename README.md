# Curso de Importação

### Para abrir
1. Extraia o ZIP.
2. Instale o Node.js 20+ caso ainda não tenha.
3. Dê dois cliques em `INICIAR_SITE.bat`.
4. O navegador abrirá em `http://localhost:3000`.

Senha padrão do painel: `admin123`.

### O que tem
- Tema preto/vermelho com caixas.
- Logo e vídeo enviados por você.
- Login com nome + código.
- Códigos aleatórios.
- Validade de 2 dias após o primeiro uso.
- Painel para ver quem está online.
- Revogar códigos.
- Player sem botão de download.

### Para deixar público na internet
Este pacote roda o site no seu computador. Para seus amigos acessarem de qualquer lugar, o servidor precisa ser publicado em uma hospedagem. O pacote já está preparado para isso.
